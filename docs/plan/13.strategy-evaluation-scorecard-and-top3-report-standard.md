# 交易策略评估评分卡与 Top3 报告标准

> 协调说明：本文晚于 `docs/plan/12.vol-execution-aware-llm-trading-optimization-plan.md`。涉及“如何定义优秀策略、如何按新标准筛选 Top3、如何组织年度/月度/基准对比报告”时，以本文为准。

## 1. 目标

为 `NQ_CME` `1m/5m/15m` `OHLCV` 研究体系建立统一的策略评估口径，使策略筛选不再只依赖单一指标，而是遵循：

```text
硬门槛过滤
  -> 样本外年化收益率优先排序
  -> 风险/稳定性/成本韧性联合复核
  -> 输出 Top3 多图表 HTML 报告
```

核心结论：

- `年化收益率` 是第一排序因素，但只在满足最低质量门槛后才有意义。
- `胜率`、`PF`、`总收益` 都不能单独代表优秀策略。
- 日内 `NQ` 策略的核心约束是：`成本后仍成立`、`跨年度稳定`、`最大回撤可承受`。

## 2. 适用范围

本文适用于：

- `Databento NQ_CME` 的 `1m/5m/15m OHLCV` 策略搜索。
- `docs/plan/9.llm-trading-optimization-factory.md` 的候选晋级阶段。
- `experiments/profit_mining/*.json` 挖掘报告的 Top3 选择。
- `src/tlm/top_strategy_report.py` 生成的 HTML 报告。

本文不适用于：

- 真实 `bid/ask` 执行验证替代品。
- 实盘准入审批。
- 高频盘口策略质量评估。

## 3. 硬门槛

只有满足以下门槛的策略，才进入正式排名池：

- `样本外净收益 > 0`
- `全激活期净收益 > 0`
- `年化交易次数 >= 1000`
- `全激活期胜率 >= 53%`
- `全激活期 Profit Factor >= 1.15`
- `成本 + 2 tick 压力后净收益 > 0`
- `年度盈利占比 >= 75%`
- `回撤收益比（return_to_drawdown） > 1`

说明：

- 如果当前时间周期没有任何策略满足全部门槛，不停止搜索；报告仍展示“最接近达标”的策略，但必须显式暴露其未通过项。
- `Sharpe > 2` 不再作为硬门槛；在当前 `OHLCV` 研究阶段，它更适合作为附加观察指标，而不是初筛淘汰条件。

## 4. 排名标准

### 4.1 一级排序：样本外年化收益率

对通过硬门槛的候选，第一排序键是：

- `annualized_net_pnl = full_after_activation.net_pnl / covered_days * 365`

这是当前项目的主目标，因为用户明确要求：

- 优先寻找 `每年都能盈利`
- 同时 `最大化盈利规模`
- 并以 `年化收益率` 作为第一因素

### 4.2 二级排序：质量补充项

当两个策略年化收益率接近时，再比较：

1. `硬门槛通过数量`
2. `年度盈利占比`
3. `测试期净收益`
4. `full/test Profit Factor 的较小值`
5. `回撤收益比`
6. `年化交易次数`

排序逻辑不是为了让低质量高收益策略长期霸榜，而是为了让：

- 高收益但极脆弱的策略靠后
- 收益略低但稳定性更好的策略靠前

## 5. 评分维度

为了便于报告解释和后续自动化，可把优秀策略分解为 5 个维度：

### 5.1 收益质量

- 样本外年化收益率
- 全激活期净收益
- 对 NQ 基准的超额收益

### 5.2 风险控制

- 最大回撤
- 回撤收益比
- 成本压力下的收益保留

### 5.3 稳定性

- 年度盈利占比
- 是否存在明显亏损年份
- 月度表现是否高度集中

### 5.4 交易结构

- 年化交易次数
- 胜率
- 平均每笔收益
- PF

### 5.5 可执行性

- 配置成本后是否仍盈利
- `+1 tick` 与 `+2 tick` 压力后是否仍成立
- 是否过度依赖少数年份或少数月份

## 6. 报告标准

Top3 HTML 报告必须包含：

- 筛选目标与排序规则
- 策略来源周期与来源挖掘报告
- 资金曲线
- 与 `NQ` 持有基准的对比曲线
- 年度表现
- 月度表现
- 年度/月度超额收益
- 成本压力结果
- 进出场 K 线示意
- 优点与缺点

如果输入包含多份挖掘报告，Top3 报告必须支持跨 `1m/5m/15m` 联合筛选。

## 7. 当前落地要求

当前版本需要按以下顺序执行：

1. 继续使用 `mine-profitable-nq` 生成 `1m/5m/15m` 挖掘结果。
2. 报告层按本文硬门槛与排序规则选择 Top3。
3. 报告默认目标改为“年化优先 + 质量复核”。
4. 若 `5m/15m` 无合格候选，报告仍可由 `1m` 策略构成，但要保留跨周期联合筛选能力。
